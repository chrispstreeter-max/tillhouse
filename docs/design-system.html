Design System Guide

All design choices live in Theme settings and apply to every section. Change them once; the whole store follows.

Start with a style direction

The quickest start is Theme settings › Theme style: choose one of the three styles (Tillhouse, Gilt or Larder) and it sets everything below, including the style direction, in one step.

Theme settings › Style direction — Luxury, Fashion, Beauty, Streetwear, Electronics & tech, Home & living, Food & beverage, General retail, Editorial or Minimal. It recomposes key sections (slideshow, collection lists, product rows, promo tiles) for that kind of store. Each demo sets it for you; change it here if you want a different combination, then fine-tune the groups below.

Colours

  • Colour schemes — each scheme has background, surface, text, muted text, border, primary, secondary and accent colours. Sections and blocks pick a scheme, so a dark band or a tinted card is one click.
  • Sale, success and warning colours — used by sale prices, badges, stock messages and alerts.
  • Keep text and background at WCAG AA contrast; Theme health warns in the editor when a scheme is too low.

Typography

  • Fonts — heading, body and accent fonts from Shopify's font library.
  • Levels — Display, H1–H4, Body, Small, Caption (all small labels: eyebrows, filter and accordion headings, badges, tab labels), Button and Navigation (menu links). For each: font, size, weight, line height, letter spacing (hundredths of an em — 16 = 0.16em) and capitalisation.
  • Mobile scale — shrinks headings on phones.

Buttons

Style (solid, outline, underline), size (small, medium, large or custom height and side padding), corner radius, border width and hover effect (fade, invert, lift).

Cards

Card style (plain, bordered, surface, elevated), shadow, corner radius, padding, image ratio and fit, hover effect, text alignment, and what cards show: vendor or subtitle, rating, badges, colour swatches, and quick add/view.

Forms

Field style (outlined, filled or underline), field height, focus style (darker border or accent ring), input corner radius and border width.

Spacing

A spacing unit that scales every gap; page width and narrow page width; section spacing, page gutters and grid gaps — each for desktop and mobile. Sections can override their own spacing (or Use global).

Borders and radius

Global border width; radius for buttons, cards, images, inputs and badges.

Images

Image corner radius and the default crop position (centre, top or bottom) for cropped images; product card image ratio and fit. Images use Shopify's responsive image sizes and load lazily below the fold. Add alt text to every image in Shopify admin.

Icons

Stroke width, size and style (outline or filled) for the theme's icon set.

Badges

Size, icons, shape, position, maximum number and two custom colour styles — see the Promotions Guide and Complete Theme Guide.

Animation

Default entrance animation, speed, distance (intensity), stagger between items and hover effect. Visitors who ask their device for reduced motion never see animation. Any section can use None.

Header and footer defaults

Default header layout (Standard, Inline, Editorial, Minimal, Campaign) and footer layout used when the Header or Footer is set to Use global.
