Theme Editor Guide

Open it from Online Store › Themes › Tillhouse › Customize. Everything below is done with Shopify's own editor — no code.

Sections

  • Add a section: in the left sidebar choose Add section (inside the template area, or in the Header/Footer group). Sections are grouped: Layout, Commerce, Media, Content, Marketing, Social proof, Storytelling, Navigation.
  • Reorder: drag a section by its handle, or use its menu › Move up / Move down.
  • Hide: the eye icon hides a section without deleting it.
  • Remove: the section's menu › Remove section.
  • Duplicate: the section's menu › Duplicate (useful for a sale version of a section with different conditions).

Blocks

Sections such as Design section, Hero, Featured product, Product information, Collection grid, Cart and Footer contain blocks.

  • Add: Add block under the section. Some blocks contain other blocks (Group, Tabs, Specifications, Complete the look).
  • Reorder: drag blocks; you can drag a block into or out of a Group.
  • Duplicate / remove: the block's menu.
  • Hide: the eye icon.

Settings that apply everywhere

Setting group Where Purpose
Section style Most sections Colour scheme, content width.
Spacing Most sections Top/bottom padding for desktop and mobile; Use global follows Theme settings › Spacing & layout.
Animation Most sections Entrance animation or the global default. Visitors who prefer reduced motion never see animation.
Device visibility Every section and block Show on desktop (990px+), tablet (750–989px) and mobile (under 750px). Hidden items leave no gap.
Scheduling Sections, Group block Start and end date/time (store time zone). Preview in editor shows scheduled items while editing.
Conditions Sections, Group block Only for logged-in or guest customers, chosen countries, cart value above an amount, products with tags, products in collections, products in stock / low stock / sold out / on sale / not on sale, or during / outside Campaign mode.

To give any block conditions, put it inside a Group block and set the conditions on the Group — e.g. a "Low stock — order soon" message that only shows on low-stock products, or a Christmas message between two dates.

Responsive layouts

Group blocks and Design sections have direction (column, row, grid, horizontal scroll), columns, alignment, gap and padding for desktop and mobile separately, plus background image, colour scheme, border and radius. Collection grids and product grids have columns for desktop, tablet and mobile. Preview each device with the icons at the top of the editor.

Dynamic sources and metafields

Many block settings show a dynamic source icon (a stack of discs). Click it to connect the setting to a product or collection field or metafield — the block then shows different content for every product.

  1. Create the metafield definition: Settings › Custom data › Products › Add definition (name, namespace and key, type).
  2. Fill it in on each product (bottom of the product page in admin).
  3. In the Theme Editor, open the block and connect the setting with the dynamic source icon.

Metafields the theme uses out of the box:

Metafield Type Used by
custom.subtitle Single line text Subtitle block, product cards
custom.badge Single line text Badge on cards and product page
custom.size_guide Page Size guide block and accordion
custom.care_instructions Rich text Materials & care accordion

reviews.rating_breakdown JSON Rating breakdown bars — if your reviews app or Shopify Flow writes it

Global settings (Theme settings)

Brand · Style direction · Colours · Typography · Spacing & layout · Buttons · Cards · Badges & labels · Badge rules · Media & forms · Icons · Animation · Header & footer defaults · Cart · Search · Conversion toolkit (recently viewed) · Promotions & merchandising · Campaign mode · Offer 1–6 · Social media · SEO & structured data · Placeholder artwork · Preview / demo states · Theme health.

Preview / demo states lets you preview sale, sold-out and campaign states in the editor without changing products. Theme health shows editor-only warnings (e.g. low colour contrast, missing metafields) — customers never see it.

Templates

Use Create template in the page selector to make alternative templates (for products, collections or pages) and assign them in Shopify admin. Each template has its own sections and settings.

Tips

  • Save often; nothing is live until the theme is published.
  • Use Undo (Ctrl/Cmd+Z) in the editor.
  • Blocks with no content show nothing to customers — for example a Rating block on products without reviews.
