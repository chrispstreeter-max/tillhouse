Bundle Builder Guide

Shoppers mix and match single items from a collection and unlock a better price at set sizes, e.g. any 3 for £27, any 5 for £40, any 10 for £75. A shopper can mix any eligible products. Once the bundle is full, extra items are charged at the single price.

  • The theme shows the builder, live price and savings, progress, and bundle grouping in the cart.
  • Shopify sets the price at checkout, using automatic discounts you create (step 4).

The theme never changes a price.

1. How it works

  • A bundle group says which collection is eligible, the single-item price, and the tiers.
  • A product variant joins a bundle only when all of these hold. One rule, the theme's eligibility rule, is used everywhere:
    1. the shopper is a retail customer (Shopify B2B buyers never get bundle pricing);
    2. the group is enabled;
    3. the product is in the group's eligible collection;
    4. the product is not on the group's excluded list;
    5. the variant is one unit:
      • Multipack variants never join. A multipack is a variant whose Quantity / Qty / Pack / Pack size / Count / Amount option, or an option with values like "3 sets" or "2-pack", starts with a number of 2 or more ("3-pack", "6x", "12").
      • "Single", "Set", "Each" and "1" are one unit.
      • A "Size" option is never treated as quantity.
    6. the variant's current price equals the group's single-item price, so a product on sale is left out automatically.
  • Pricing shown to shoppers: the best completed tier, plus any remaining items at the single price. For example, 7 items on 3/5/10 tiers = the 5-item price + 2 singles, never 7 × the 5-item rate.
  • Size limit: each group has its own maximum items (default 10, ceiling 50).

2. Create the metaobject definitions (once)

Settings › Custom data › Metaobjects › Add definition. Turn Storefronts access on for both definitions.

Bundle tier (type bundle_tier)

Field Key Type
Size size Integer (display name)
Price price Decimal (the total price for that many items)
Label label Single line text (optional)

Bundle group (type bundle_group)

Field Key Type Notes
Title title Single line text display name, e.g. "Snack bundle"
Heading heading Single line text optional; builder heading
Intro intro Multi-line text optional
Unit price unit_price Decimal the single-item price eligible variants must have
Eligible collection eligible_collection Collection reference
Tiers tiers Metaobject › Bundle tier, list
Max items max_sets Integer blank = 10, ceiling 50
Excluded products excluded_products Product reference, list optional
Allow mixing allow_mixing True or false blank = yes
Enabled enabled True or false blank = yes; false hides the group everywhere
Progress / tier / complete messages progress_message, tier_message, complete_message Single line text optional; placeholders {remaining}, {size}

Optional collection metafield custom.bundle_group: a Metaobject reference to a Bundle group. Use it on a browsing collection that should show the "Build your …" button for a group.

3. Pages and placement

  • Builder page: Online Store › Pages › Add page "Build a bundle" (handle build-a-bundle), template build-a-bundle. Links can pick a group and a size, e.g. /pages/build-a-bundle?group=snack-bundle&size=5.
  • Product page: the Build a bundle block appears only on eligible products, with links into the builder.
  • Collection banner: the "Build your …" button appears on a group's eligible collection.
  • Homepage: add the Build your bundle promo section and enter the bundle group's handle (shown on its entry under Content › Metaobjects, for example snack-bundle).
  • Builder page default: in the Bundle builder section, the default group is also set by its handle.
  • Cart and drawer: lines that belong to a bundle are grouped, with a progress bar and edit/remove actions.

4. Discounts: what actually sets the price

Create one automatic discount per tier: Discounts › Create › Amount off products.

  • Method: Automatic. Value: fixed amount = size × unit price − tier price (e.g. 5 × £10 − £40 = £10), applied once per order.
  • Minimum purchase: minimum quantity of items = the tier size.
  • Applies to: specific products / variants. Pick the single-unit variants of the eligible products, the same ones rule 5 above accepts. Don't pick the whole collection, or multipack variants and sale-priced items would count towards the minimum.
  • Eligibility: your retail markets (or All customers if you don't sell B2B). Check Shopify's B2B discount settings if you also sell to companies.
  • Combinations: decide whether bundles stack with your other discounts. With none ticked, Shopify applies whichever single discount is better for the shopper.

Shopify applies only the best qualifying tier for a group. Test every tier at checkout, stopping before payment, before going live.

5. Limits

  • The theme's prices are explanatory. Shopify's discount decides the final price, and the cart shows Shopify's figures.
  • Any eligible single unit in the cart counts towards a bundle, whether it came from the builder or a product page. Line properties only carry the bundle ID for editing.
  • Markets and currencies: the builder only accepts items whose price, in the shopper's market, equals the group's unit price. Markets with a price adjustment, a catalog price list or another currency change that price, so the builder hides the items there. Use bundles in markets that sell at your store prices.
  • Bundles are retail only. On a B2B storefront the builder shows a notice instead. If a page with the handle wholesale-order exists (Trade portal), the notice links to it.
