Setup Checklist

Work through this list before publishing Tillhouse. Tick items as you go.

Shopify settings

  • Settings › Store details: store name, contact email, address, currency.
  • Settings › Users and permissions: staff accounts set up.
  • Settings › Customer accounts: choose new or classic accounts, or off.
  • Settings › Markets: countries, currencies and languages you sell in.

Branding

  • Theme settings › Brand: logo, light logo (for dark or transparent headers), logo width, favicon.
  • Theme settings › Style direction, Colours, Typography, Buttons, Cards reviewed.
  • Theme settings › Social media profile links.
  • Theme settings › SEO & structured data: social sharing image.

Domain

  • Settings › Domains: domain connected, set as primary, SSL active.

Navigation

  • Online Store › Navigation: main menu (up to three levels) and footer menus.
  • Header: layout, menu, highlighted item, icons, sticky behaviour.
  • Mega menus added for the top-level items that need them (names match exactly).
  • Menu checked on a phone (menu drawer).

Collections

  • Collections created with images and descriptions.
  • Shopify Search & Discovery installed; filters added (price, availability, colour, size…).
  • Collection templates chosen; editorial tiles added where useful.

Products

  • Titles, descriptions, prices; compare-at prices only where genuinely reduced.
  • At least two images per product (the second is the card hover image), with alt text.
  • Variants and colour swatches (category metafield swatches) set.
  • Inventory tracking on (needed for stock and low-stock messages).
  • Tags for badges (new, bestseller, trending, staff-pick, badge:Your text).
  • Metafield definitions created and filled for the blocks you use (subtitle, size guide, FAQ, siblings, Complete the look).

Product templates

  • Default product template arranged; alternative templates (editorial, minimal, sale) assigned where wanted.
  • Reviews app installed, its block added to Product reviews.
  • Sample text in accordions, storytelling and trust blocks replaced or removed.

Payments

  • Settings › Payments: Shopify Payments or a provider activated; wallets (Shop Pay, Apple Pay, Google Pay) on.
  • Test order placed in test mode, then test mode turned off.

Shipping

  • Settings › Shipping and delivery: zones, rates, free-shipping threshold, local pickup if offered.
  • Delivery estimate block values match your real delivery times.

Taxes

  • Settings › Taxes and duties configured for your markets; Taxes included note matches.

Policies

  • Settings › Policies: refund, privacy, terms of service, shipping, contact information.
  • Footer links to policies.

Search

  • Theme settings › Search: presentation, popular searches (your own terms), quick-links menu, featured collection.
  • Searched for a few products on desktop and phone.

Cart

  • Theme settings › Cart: drawer or page, order notes.
  • Cart blocks: progress bar, upsells, discount code, gift options as needed.

Discounts and promotions

  • Every enabled offer (Theme settings › Offer 1–6) has a matching discount in Shopify admin › Discounts and Discount exists in Shopify admin ticked.
  • Offer eligibility, tiers and dates match the discount; each tested at checkout.
  • Free shipping / free gift thresholds confirmed only after setting them up in Shopify.
  • Campaign mode off, or scheduled and linked to a live offer.

Mobile

  • Preview on an iPhone (Safari) and an Android phone (Chrome): header, menu, search, product page, cart drawer, checkout.
  • Blocks hidden or shown per device where needed.

Testing

  • Add to cart, quick add, quick view, variant changes, quantity, discount code and checkout tested end to end.
  • Contact form and newsletter sign-up tested.
  • Theme health (editor) warnings resolved.
  • No placeholder artwork or sample text left (or placeholder artwork turned off).

Analytics

  • Settings › Customer privacy (cookie banner) configured.
  • Google & YouTube, Meta or other sales-channel apps connected; Shopify Analytics reviewed.

SEO

  • Online Store › Preferences: homepage title and meta description.
  • Product and collection SEO titles/descriptions; image alt text.
  • Redirects for any old URLs (Online Store › Navigation › URL redirects).

Optional modules

  • Bundle builder:
    • Create the Bundle tier and Bundle group definitions.
    • Add a page with the build-a-bundle template.
    • Create one automatic discount per tier.
    • Test every tier at checkout (Bundle Builder Guide).
  • Trade portal:
    • Turn on Shopify B2B and create a catalog.
    • Create the Wholesale program entry.
    • Add the wholesale and wholesale-order pages.
    • Restrict retail discounts to retail markets.
    • Test a B2B checkout (Trade Portal Guide).

Launch

  • Theme backed up: Online Store › Themes › … › Download theme file.
  • Theme published.
  • Store password removed (Online Store › Preferences).
  • Test order placed on the live store and refunded.
