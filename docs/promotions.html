Promotions Guide

The rule: the theme presents, Shopify discounts

The theme (Theme Editor) Shopify (admin)
Badges, banners, announcements, product-page offer panels, multi-buy tables, cart progress bars and reminders, campaign bar The price change itself: Discounts (automatic or code), free shipping (Settings › Shipping and delivery), gift products

Every offer, the free-shipping threshold and the free-gift threshold has a confirmation box. Until it is ticked, customers see nothing. In the Theme Editor unconfirmed items appear with a dashed outline and “Preview – not live” (switch previews off in Promotions & merchandising). Offers hide automatically outside their start/end dates and only appear on products that match their eligibility.

Theme settings

Promotions & merchandising — free shipping threshold + set up in Shopify shipping settings confirmation; free gift threshold, description + confirmation; editor preview switch.

Offer 1 – Offer 6 — each offer has:

Setting Notes
Enable offer / Discount exists in Shopify admin Both required for customers to see it.
Offer type BOGO, Buy X get Y, buy more save % (tiers), multi-buy price (3 for £40), spend £X get % off, spend £X get £ off, spend £X free shipping, free gift, sale / campaign, custom.
Badge label, headline, details Badge on cards; headline/details for panels, banners and the multi-buy block.
Tiers quantity or spend = reward, separated by semicolons: 2=15% off; 3=20% off; 5=25% off · 3=£40 in total · 2=Second item 50% off · 150=10% off; 250=15% off.
Spend threshold For spend, free shipping and free gift offers; drives cart progress.
Discount code Optional; shown when the discount needs a code.
Applies to All products, a collection, specific products, or a product tag — keep in step with the discount's eligibility.
Starts / Ends Optional (store time zone). Ends adds countdowns and hides the offer afterwards.
Display Badge on cards, panel on product pages, reminder in the cart, badge style, link.

Badges & labels — position, maximum per card, shape; Sale (text, % off, amount off), Sold out, New (days or tag), Low stock, Best seller, Limited, Exclusive, Online only (by tag), two collection badges, metafield badge (custom.badge), custom badge: tags, campaign badge; a style for each.

Components

Every component below reads the same Offers 1–6, so an offer is set up once and shown wherever you place it.

Component Where to add it
Promotional banner Add section › Promotional banner: full image, split, boxed or slim bar; mobile image; background colour; countdown; scheduling; link to an offer to reuse its copy and hide when not live.
Offer announcement Header › Announcement bar › Add block › Offer announcement.
Promotion tiles Add section › Promotion tiles; each tile can link to an offer and stays hidden until it is live.
Offers panel Product information › Offers (optional tiers, hide one offer).
Multi-buy offer Product information › Multi-buy offer — tiers from an offer or manual tiers (with their own confirmation); tapping a quantity tier sets the quantity.
Promotional badge Product information › Promotional badge — type, custom text, colour, size, icon, alignment, only when the condition is met.
Promotion Any block area (product information, Design section, Hero, Group) › Add block › Promotion: an offer (Panel, Minimal, Outlined or Banner; tiers as cards, list or pills) or a message only.
Offer tile Collection grid › Add block › Offer tile: an offer between products; offers limited to one collection only show there.
Cart progress / reminders Cart drawer or Cart page › Progress bar, Offer reminders, Promotion message.

Campaign Mode

Theme settings › Campaign mode switches the whole store into a seasonal campaign on a schedule:

  • Campaign bar above the header: text, link, countdown to the end date, colour scheme.
  • Colour overrides: accent and sale colours while the campaign is live.
  • Campaign badge on products in a chosen collection.
  • Section conditions: any section's Conditions › Campaign can be set to show during or outside the campaign — e.g. a sale slideshow during, the regular slideshow outside.

The campaign is live when it is enabled and inside its start/end dates. Set Only while this offer is live to tie it to an offer: then an unconfirmed, disabled or expired offer keeps the entire campaign off. If you run a campaign without linking an offer, make sure its text only describes discounts that exist in Shopify.

Preview in the editor before the start date with Theme settings › Preview / demo states › Campaign: active (customers are unaffected).

Example: “Buy 2, save 15% on knitwear”

  1. Shopify admin › Discounts › Create discount › Amount off products — automatic, 15%, minimum quantity 2, applies to the Knitwear collection.
  2. Theme settings › Offer 1 — enable; type Buy more, save % (tiers); label Buy 2, save 15%; tiers 2=15% off; applies to A collection › Knitwear; tick Discount exists in Shopify admin.
  3. Optional — product page Multi-buy offer block (Offer 1); home page Promotional banner linked to Offer 1; Offer announcement in the announcement bar.

Example: Black Friday campaign

  1. Create the discount(s) in Shopify admin and confirm the matching offer (e.g. Offer 6, type Sale / campaign, with an end date).
  2. Campaign mode: enable, name, start/end, Only while this offer is live → Offer 6, bar text and link, optional colour overrides, campaign collection and badge.
  3. Duplicate your slideshow; set the copy's Conditions › Campaign to During and the original's to Outside.

Example: BOGO — buy one, get one free

  1. Shopify admin › Discounts › Create discount › Buy X get Y — customer buys 1 item from the chosen products, gets 1 item at 100% off; automatic.
  2. Theme settings › Offer 2 — enable; type Buy one, get one (BOGO); label Buy one, get one free; headline and details; Applies to the same products or collection; tick Discount exists in Shopify admin.
  3. Show it: Promotion block on the product page, Offer tile in the collection, Offer announcement in the announcement bar.

Example: Spend $50 save 10%, $100 save 15%, $150 save 20%

  1. In Shopify admin › Discounts, create three automatic Amount off order discounts: 10% with minimum purchase $50, 15% with minimum $100, 20% with minimum $150 (Shopify applies the best one).
  2. Theme settings › Offer 3 — type Spend £X, get % off; tiers 50=10% off; 100=15% off; 150=20% off; spend threshold 50; tick Discount exists in Shopify admin.
  3. Add a cart Progress bar block (spend tiers) and, if you like, a Promotion block with tiers as cards.

Promotional messaging without a discount

Use the Promotion block's A message only option, the announcement bar, or any text block for messages such as "Complimentary alterations in store". The theme adds no discount wording and applies nothing — write only what is true.

How to avoid misleading promotions

  • Create the discount in Shopify first, then tick Discount exists in Shopify admin. Until then customers see nothing.
  • Keep Applies to, dates and tiers exactly in step with the Shopify discount.
  • Use end dates: offers disappear automatically when they end.
  • Link Campaign mode to an offer (Only while this offer is live) so a campaign can't outlive its discount.
  • Test at checkout (Shopify's test mode or a test order) before announcing an offer.
  • Compare-at prices should be genuine previous prices; the Sale badge and savings are calculated from them.
