Troubleshooting

Problem Cause and fix
An offer, badge or banner doesn't appear for customers The offer isn't enabled + confirmed, is outside its dates, or the product doesn't match Applies to. In the editor, unconfirmed offers show with a dashed outline and “Preview – not live”.
The discount isn't applied at checkout The theme doesn't create discounts. Create or fix it in Shopify admin › Discounts and make its eligibility match the offer.
Free shipping bar missing Enable it and tick Free shipping above this amount is set up in Shopify shipping settings (Promotions & merchandising), and add a Progress bar block to the cart drawer. It appears once the cart has items.
Campaign bar not showing Campaign mode must be enabled, inside its dates, and — if linked — its offer must be live. Preview with Preview / demo states › Campaign: active.
Mega menu doesn't open The Mega menu block's Menu item must match a top-level menu item's title exactly (not case-sensitive).
A product block doesn't show Blocks with nothing to show render nothing — e.g. Rating without reviews, Size guide without a guide, FAQ without content, Subtitle without the metafield. Add the content or connect the metafield.
Size selector or Colour selector shows nothing Its Options to show must match your option names (e.g. Size, Colour or Color). Leave it empty to show all options.
Gallery is on the wrong side Product information › Gallery position and Column widths.
A block is missing on phones or desktop Check the block's Show on desktop / tablet / mobile and any Group conditions it sits in.
Search shows nothing before typing Add popular searches, a quick-links menu or a featured collection in Theme settings › Search; empty parts are hidden.
Offer tile or Promotion block not visible The offer must be live (enabled, confirmed, inside its dates). An offer limited to one collection only shows on that collection.
No filters on collections Install Shopify Search & Discovery and add filters; enable filtering in the Collection grid section.
Colour swatches show as text Set the product category and link the Color option to category values; for filters set presentation to Swatch in Search & Discovery.
Low stock badge never appears Variant must track quantity with Continue selling when out of stock off, and stock must be at or below the threshold.
Stars/ratings missing Install a review app that writes reviews.rating and reviews.rating_count, and add its app block to Product reviews.
Complementary products / “Bought together” empty Configure complementary products in Search & Discovery.
Discount code field says the code couldn't be applied The code doesn't exist, has expired or its requirements aren't met; Shopify decides. Codes can always be entered at checkout.
Gift wrap does nothing Choose a gift wrap product in the block; it must be published to the Online Store sales channel.
Placeholder artwork on the live store An image setting is empty. Choose an image, or turn off Theme settings › Placeholder artwork to use Shopify's plain placeholders.
Product grid missing on the storefront Grids without a collection (or with an empty collection) are hidden from customers and shown as placeholders in the editor only. Choose a collection with products.
Sections appear/disappear unexpectedly Check the section's Scheduling, Device visibility and Conditions.
Animations feel slow or distracting Theme settings › Animation, or set a section's animation to None. Visitors who prefer reduced motion never see animation.
Editor shows “translation missing” Check the store's language settings; the theme ships English and French. Edit texts in Online Store › Themes › … › Edit default theme content.

Still stuck? Contact support via https://chrisps.ca with your store URL, theme version (6.0.1), the page URL and what you expected to happen.
